# AIEdit

[![CI](https://github.com/tongzhendiao-droid/AIEdit/actions/workflows/ci.yml/badge.svg)](https://github.com/tongzhendiao-droid/AIEdit/actions/workflows/ci.yml)

快速、带 AI 辅助的文本与二进制文件查看器。用 C++20 和 Qt 6 编写，以查看为主、编辑为辅。

> 当前进度：已完成 **M9b**（Markdown：边写边预览，阅读模式读排好的版，列表自动续行、表格一键对齐，导出 HTML 和 PDF，AI 一键整理成表格）。之前的 M9 是 Windows 版：安装包，右键菜单「用 AIEdit 打开」，打开方式和默认应用。计划见 [DESIGN.md](DESIGN.md)。

## 功能

**打开任意大小的文件**
- 用 mmap 映射文件，只绘制屏幕上可见的行，TB 级文件也能流畅滚动。
- 大文件在后台建行索引，第一屏马上就能显示。
- 超长行（比如压缩过的 JSON）会自动拆成多行显示，不会卡住。

**文本视图**
- 中日韩文字、emoji、Tab 都能正确显示；控制字符显示为 ␀、␛ 这类可见符号。
- 长行默认按窗口宽度自动换行，看小说、长段落不用横向滚动；`Alt+Z` 可以关掉，改为横向滚动。
- 自动识别编码（UTF-8/16/32、GB18030、Big5、Shift_JIS 等），也可以在状态栏一键切换（20 种）。
- 语法高亮支持 300 多种语言（借助 KDE 的 KSyntaxHighlighting），可在状态栏切换语言。
- 配色方案（视图 →「配色方案」）：默认跟随系统，也可以选 Monokai、Dracula、Solarized、GitHub、Nord、Tokyo Night 等 29 套主题，编辑区、十六进制视图和整个界面一起变。编辑区字体也可以换（视图 →「编辑区字体」）。
- 显示行号；`Ctrl+G` 转到行号，也可以输入 `0x1F` 这样的偏移。

**读书**
- 阅读模式（`F9`）：不显示行号，正文在中间成一栏，行距加大，换成宋体一类的字体；记住读到哪里，状态栏显示读了百分之几。
- 目录（`Ctrl+Shift+O`）：自动找出「第三回」「五帝本纪第一」「卷一」「序」这类标题，点一下就跳过去，读到哪一章就标出哪一章。找不到或找错时，可以让 AI 找出这本书的标题是什么样子，规则在本机运行，并为这本书记住。
- AI 读书：在目录里右键某一章，或者用「AI」菜单，可以总结、翻译（文言文译成白话文）或解释这一章。

**写 Markdown**
- 视图 →「Markdown 预览」（`Ctrl+4` 或 `Ctrl+Shift+V`）：左边写，右边显示排好的版，停顿一下就更新，两边按标题对齐滚动。表格、任务列表、代码着色都有，颜色跟着配色方案；图片只读本机的，不从网络取。
- 阅读模式（`F9`）下直接读排好的版，目录列出各级标题。
- 列表里回车自动续上（编号递增），在空条目上回车结束列表；`Tab` 把列表项缩进一级。
- 编辑 →「Markdown」：加粗、斜体、删除线、行内代码、链接（`Ctrl+K`）、标题、列表、任务列表、引用、代码块、插入表格、格式化表格（各列对齐，中文按两个字宽）。再点一次就去掉。
- 用 AI 修改（`Ctrl+I`）时可以一键「整理成表格」「整理排版」「改成列表」「纠正错别字」。
- 文件 →「导出为 HTML」「导出为 PDF」。

**十六进制视图**
- 偏移、十六进制、字符三栏，按字节类别着色。
- 可复制为十六进制、文本、C 数组或偏移。
- 数据检查器：把光标处的字节解析为各种整数、浮点数、Unix 时间和 UTF-8 字符，可切换大小端。

**联动和搜索**
- 文本、十六进制、并排三种模式，光标和选区始终同步。
- 查找支持三种模式：
  - 文本：可选区分大小写。
  - 正则表达式。
  - 十六进制：用 `??` 表示任意字节，如 `4D 5A ?? 00`。
- 搜索在后台运行，大文件也不会卡住界面。搜索 GBK 文件时，会跳过落在字符中间的假匹配。
- 替换（`Ctrl+H`）：逐个替换，或全部替换（一步就能撤销）。正则模式下用 `$1` 或 `\1` 引用分组，`\n` 插入换行（自动用文件原来的换行符）。

**编辑**（16 MiB 以内的文本文件）
- 直接输入，支持中文输入法；撤销、重做、剪切、粘贴，选中多行时 `Tab` / `Shift+Tab` 整体缩进。
- 回车沿用上一行的缩进；`Tab` 跟随文件本身的风格（制表符，或 2、4 个空格）。
- 保存（`Ctrl+S`）时保持文件原来的编码、BOM 和换行符；先写临时文件再整体替换，保存一半出错也不会损坏原文件。
- 有未保存的修改时，标签页标题前显示 `*`；关闭标签页或窗口前会询问是否保存。
- 新建文档：`Ctrl+N`、标签栏右侧的 `+`，或双击标签栏空白处；第一次保存时选择保存位置。
- 转换编码：状态栏的编码按钮 →「以其他编码保存」，比如把 GBK 文件存成 UTF-8；有无法识别的字节、或新编码表示不了的字符时会先告诉你。
- 统一换行符：点状态栏的换行符（LF / CRLF），可以把所有行转换为 LF、CRLF 或 CR，一步就能撤销。
- 行操作（编辑 →「行操作」）：排序（数字按大小）、删除重复行、删除空行、删除行尾空白，上移、下移行（`Alt+↑` / `Alt+↓`），复制行（`Ctrl+D`）。选中几行就只处理那几行，每个操作一步就能撤销。
- 二进制文件和更大的文件只能查看。

**记住上次的样子**
- 关闭 AIEdit 时不再询问要不要保存：未保存的修改（包括没起名字的新文件）会自动留下，下次启动原样回来，撤销一步就回到磁盘上的版本。编辑时也会随时备份，程序崩溃了也能找回。关闭单个标签页时仍会询问。
- 文件菜单 →「最近打开」列出最近的 10 个文件。
- 每个文件都记住光标、读到哪里（屏幕顶端那一行）、视图模式和手动选过的编码，下次打开回到原处。读长篇小说也不用自己记页码。
- 不带文件启动时，恢复上次关闭时打开的那些标签页和文件夹；从文件管理器打开某个文件时，只打开它。

**文件夹**（`Ctrl+Shift+D`）
- 文件 →「打开文件夹」，或者把文件夹拖进窗口、`aiedit 某个文件夹`：左侧显示文件树。不是工程，不在文件夹里存任何东西。
- 单击（或用方向键停在）一个文件就在预览标签页里显示，再看下一个时替换它，不会开出一堆标签；双击、回车或开始编辑，就变成普通标签页。
- 只列名字，文件和文件夹看图标就能分清；鼠标停在名字上，显示大小、修改时间和按内容识别出的类型（PNG、ELF、ZIP，文本标出 UTF-8、GB18030 等编码）。扩展名和内容对不上的（JPEG 改名成 .png、下载失败的 HTML 页面叫 .zip），图标换成警告标志。
- 在筛选框里输入 `*.log`、`error` 或 `logs/*.gz`，列出整个文件夹里所有名字相符的文件。
- 右键：新建文件、新建文件夹、重命名（`F2`）、移到回收站（`Delete`）、复制路径、在这个文件夹里查找。已打开的文件改名后，标签页跟着到新路径。
- **问 AI 这个文件夹里是什么**：在本机整理出文件数量、类型、大小、结构，以及 README 这类文件的开头几行，只把这份摘要交给 AI，文件本身不发送。

**比较**（文件 →「比较」）
- 与磁盘上的版本比较（看看还没保存的改动）、与剪贴板比较、与另一个文件比较、比较两个文件；在文件夹面板里选两个文件，右键「比较这两个文件」。
- 左右两栏对齐显示，删除的标红、增加的标绿，行内改了的词再深一层标出。右边细栏标出所有改动的位置。`F7` / `Shift+F7` 到下一处、上一处；双击在那个文件的那一行打开。
- 可以忽略空白、大小写、换行符；「只看差异」把相同的部分折叠起来。GBK 文件和它的 UTF-8 副本算相同。百万行的文件也能比较，在后台进行。
- **二进制文件**按字节对比：不同的字节标出颜色；插入或删除了内容、后面整体错开时会说明从哪里起错开了几个字节。PE（.exe、.dll）和 ELF（Linux 程序、.so）会显示差异在哪个节、地址多少，并用 Capstone 反汇编两边差异附近的指令，改了哪条指令一目了然。
- **问 AI 改了什么**：把差异（文本是统一 diff，二进制是位置、字节和反汇编）交给 AI 总结、解释。

**看日志**
- 文件变化时自动重新加载（有未保存的修改时不会覆盖它们）。
- 「跟随文件末尾」（`Shift+F5`）的效果和 `tail -f` 一样。
- **在文件夹里查找**（`Ctrl+Shift+F`）：在一个文件夹（可含子文件夹）的所有文件里查找文本、正则，或者直接用过滤面板最近运行的规则，比如一次查完一个程序的全部日志。每个文件按它自己的编码读，二进制文件和隐藏文件夹会跳过；结果按文件分组，双击打开文件并跳到那一行。
- 日志被 logrotate 截断时不会崩溃。
- **过滤行**（`Ctrl+Shift+L`）：在文档下方只列出符合规则的行。规则由几条「包含」「排除」的正则表达式组成，还能比较捕获到的数字，比如 `took (?<ms>\d+)ms` 加上 `ms > 1000`，就只看耗时超过一秒的请求。
- **一句话让 AI 写规则**：比如「超过一秒的错误，不要心跳」。AI 只看到你的描述和最多 80 行样例（每行最多 200 个字符）；它写出的条件就摆在面板里，可以检查、修改，然后在本机对整个文件运行。
- 结果按日志级别着色（ERROR 红、WARN 橙、DEBUG 灰），匹配到的部分高亮。用方向键浏览时原文跟着跳到那一行；回车或双击回到原文继续看。`Ctrl+C` 复制选中的结果行。
- 过滤在后台进行，结果边找边显示；300 MB 的日志约 0.6 秒。日志变长时只读新增的部分，配合「跟随文件末尾」可以只盯着错误看。

**用 AI 修改**（`Ctrl+I`）
- 说一句要怎么改，比如「把注释翻译成英文」「把 print 换成 logging」：改的是选中的文字，没有选中时是整个文件。
- AI 的修改在一个对比标签页里逐处确认：每处默认接受，空格切换接受或拒绝，`Ctrl+Enter` 应用，作为一步撤销写进文档。没改的地方字节不变，编码和换行符照旧。
- 太长的文字不整段发送：AI 根据样例写一条修改规则（删除哪些行、做哪些正则替换），在本机对全部文字执行，结果同样先确认再写入。

**AI 助手**（`Ctrl+Shift+A`）
- 选中文本或字节，可以一键解释、翻译、总结；也可以直接提问和追问，回答以流式显示。
- 「这是什么文件」只把在本机计算的摘要（类型、熵、字符串、开头字节）发出去，不发送文件本身。
- 发送前可以预览完整的请求内容，面板会写明将附带什么。
- **AI 能自己查文件**：问「这个日志里为什么报错」时，AI 会调用本地工具在文件里搜索、读取需要的片段，不用把整个文件发出去；要统计时（「有多少次超时」），它会在本机跑过滤规则，只拿回行数和前几行。每一次调用都会显示在对话里。
- **字段标注**：AI 认出二进制结构后，会把字段用颜色标在十六进制视图上，鼠标悬停显示字段名和含义。
- 默认使用 DeepSeek，也支持其他 OpenAI 兼容服务（通义、Kimi、本地的 Ollama 等）。

设置 API key 有两种方式：
- 在菜单「AI → AI 设置」里填写。key 只保存在本机的 `~/.config/AIEdit/api-key`，只有你能读取。
- 用环境变量，此时 key 不会写入文件：

```bash
AIEDIT_API_KEY=你的key ./build/src/aiedit
```

**标签页**
- 「+」在最后一个标签后面；中键单击关闭；`Ctrl+Shift+T` 重新打开刚关闭的标签页，回到原来的位置。
- 右键标签：关闭其他、左侧、右侧、已保存的、全部；固定；复制路径或文件名；在文件管理器或文件夹面板中显示；和磁盘上的版本或另一个标签页比较；重命名。
- 固定的标签页排在最前，批量关闭时留下，下次打开还是固定的。

**快速打开和跳转**
- `Ctrl+P` 快速打开：已打开的、最近打开的，以及文件夹里的所有文件（git 仓库里不列 `.gitignore` 写的文件），按顺序输入名字里的字母就行（`mwc` 找到 MainWindow.cpp），`名字:42` 打开并跳到第 42 行。
- `Ctrl+Shift+P` 命令面板：输入名字就能执行菜单里的命令，右边写着快捷键。在快速打开里输入 `:42` 跳到第 42 行。
- `Alt+←` / `Alt+→` 后退、前进：回到跳转之前的位置，跨文档也行。
- 书签：`Ctrl+F2` 设置，`F2` / `Shift+F2` 到下一个、上一个；编辑时跟着文字移动，下次打开还在。
- `Ctrl+F3` 查找下一个选中的文字或光标所在的词。

**编辑**
- `Ctrl+/` 注释或取消注释选中的行，注释符号按文件的语言来（`//`、`#`、`--`，CSS 和 HTML 用块注释）。
- `Ctrl+L` 选中整行（再按多选一行，三击也行），`Ctrl+Shift+K` 删除行，`Ctrl+J` 合并行，`Shift+Alt+↑/↓` 向上、向下复制行，`Ctrl+Enter` / `Ctrl+Shift+Enter` 在下方、上方插入一行。
- 大写、小写转换（编辑 →「大小写转换」）。`Home` 先到行首文字处再到行首，`Ctrl+↑/↓` 只滚动不移动光标。

**窗口**：`F11` 全屏，`Ctrl+Shift+N` 新建窗口，`Ctrl+B` 显示或隐藏左侧的面板，单击状态栏的行号转到某一行。

**其他**：拖放打开文件、缩放、中文界面。

## 构建

依赖：
- 必需：CMake 3.21 或更高、支持 C++20 的编译器、Qt 6.5 或更高（Core、Gui、Widgets、Concurrent、Network、Test）。
- 可选：
  - KSyntaxHighlighting：语法高亮。
  - uchardet：更准确的编码识别。
  - Capstone：比较二进制文件时反汇编差异附近的代码。
  - Qt 的 `lrelease`：编译中文界面翻译。

**Ubuntu / Debian**

```bash
sudo apt install build-essential cmake pkg-config qt6-base-dev qt6-l10n-tools libkf6syntaxhighlighting-dev libuchardet-dev libcapstone-dev
```

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
```

```bash
cmake --build build -j
```

```bash
./build/src/aiedit 文件1 文件2
```

也可以打开一个文件夹：`./build/src/aiedit 某个文件夹`。

**Windows**

需要 Visual Studio 2022 或更新的版本（含「使用 C++ 的桌面开发」）、Qt 6.8 或更高的 MSVC 版本、git 和 Perl（比如 Strawberry Perl）。以下命令在「x64 Native Tools Command Prompt」里运行，Qt 的路径换成你自己的。

先编译可选的库（KSyntaxHighlighting、uchardet、Capstone），只需要一次：

```bat
powershell -ExecutionPolicy Bypass -File packaging\windows\build-deps.ps1 -Qt C:\Qt\6.10.3\msvc2022_64 -Prefix C:\aiedit-deps
```

```bat
cmake -S . -B build -G Ninja -DCMAKE_BUILD_TYPE=Release "-DCMAKE_PREFIX_PATH=C:\Qt\6.10.3\msvc2022_64;C:\aiedit-deps"
```

```bat
cmake --build build
```

打安装包和 zip（需要 Inno Setup 6），结果在 `dist` 里：

```bat
powershell -ExecutionPolicy Bypass -File packaging\windows\package.ps1
```

## 安装到桌面（Linux）

安装到 `~/.local`，不需要 sudo：

```bash
cmake -S . -B build-release -DCMAKE_BUILD_TYPE=Release -DCMAKE_INSTALL_PREFIX="$HOME/.local" -DAIEDIT_BUILD_TESTS=OFF
```

```bash
cmake --build build-release -j && cmake --install build-release
```

然后注册到桌面：

```bash
packaging/linux/register.sh --default
```

注册后：
- 应用菜单里出现 AIEdit。
- 文件管理器右键 →「脚本」→「用 AIEdit 打开」，对任何文件和文件夹都可用；文件夹会在文件夹面板里打开。
- 加上 `--default` 时，纯文本、日志、Markdown、JSON/XML/YAML、二进制和可执行文件默认用 AIEdit 打开。你已经指定给其他程序的类型（C/C++ 源码、shell 脚本、CSV）保持不变，因为 AIEdit 目前还不能编辑。

AIEdit 只保留一个窗口：再打开文件时，会在已有窗口里新开标签页。需要单独的窗口时用 `aiedit --new-window`。

## 安装（Windows）

安装包由 CI 生成：在 GitHub 的 Actions 页面打开最近一次成功的运行，下载「AIEdit-windows-x64」（保留 30 天），里面有安装包 `AIEdit-<版本>-windows-x64-setup.exe`，和不用安装、解压就能用的 zip。

- 默认只为当前用户安装，不需要管理员权限；也可以选为所有用户安装。
- 安装时可选：
  - 文件和文件夹的右键菜单「用 AIEdit 打开」。Windows 11 上在「显示更多选项」里。
  - 在「打开方式」里列出 AIEdit（文本、日志、数据、源码和二进制文件）。
- 要让某类文件默认用 AIEdit 打开：「设置 → 应用 → 默认应用 → AIEdit」，逐个类型选。Windows 不让程序自己设成默认。
- 安装包没有签名，第一次运行时 SmartScreen 可能拦下，点「更多信息 → 仍要运行」。
- 在「设置 → 应用」里卸载，右键菜单和打开方式会一起删掉。

## 测试

```bash
ctest --test-dir build --output-on-failure
```

GUI 测试以 offscreen 方式运行，不会弹出窗口。如果设置了 `AIEDIT_SCREENSHOT_DIR`，测试会把截图保存到这个目录。

## 翻译

界面字符串在源码中用英文书写并包上 `tr()`。修改界面文字后，运行下面的命令更新 `translations/*.ts`，再补全译文（可以用 Qt Linguist）：

```bash
cmake --build build --target update_translations
```
